# 管理コンソール仕様 — aiaiai

## 概要

aiaiaiの管理コンソールは、収集パイプラインの監視・記事の品質管理・法務対応・システム設定を一元管理するための管理者専用画面である。Next.js App Routerの `(admin)` ルートグループで実装し、認証による保護を行う。

---

## 1. 管理画面共通仕様

### 1.1 認証・認可

| 項目 | 仕様 |
|---|---|
| 認証方式 | MVP: 環境変数ベースの簡易認証（`ADMIN_PASSWORD`）。将来: NextAuth.js |
| セッション | HTTPOnly Cookie、有効期限24時間 |
| 認可 | MVP: 単一管理者ロール。将来: ロールベース（admin/editor/viewer） |

### 1.2 共通UI

| 要素 | 仕様 |
|---|---|
| レイアウト | サイドバーナビゲーション + メインコンテンツ |
| ナビゲーション | ソース管理 / ジョブ管理 / 記事管理 / 設定 |
| 通知 | 画面右上にトースト通知（成功/エラー/警告） |
| 確認ダイアログ | 破壊的操作（削除・非公開化）は確認ダイアログを表示 |
| レスポンシブ | デスクトップ優先（管理画面はPC操作を想定） |

## 2. `/admin/sources` — ソース管理

### 2.1 機能概要

収集対象ソースの追加・編集・停止・削除を行う画面。

### 2.2 一覧画面

| カラム | 内容 | ソート | フィルター |
|---|---|---|---|
| ソース名 | Source.name | ○ | テキスト検索 |
| 種別 | official / rss / github / x | ○ | ドロップダウン |
| 取得方法 | fetchMethod（rss / html_scrape / github_api / x_api） | ○ | ドロップダウン |
| 取得頻度 | fetchFrequency（hourly / daily / weekly） | ○ | ドロップダウン |
| 信頼スコア | trustScore（0.0〜1.0） | ○ | スライダー |
| ステータス | active / paused / disabled | ○ | ドロップダウン |
| 最終取得日時 | lastFetchedAt | ○ | — |
| 取得件数（直近） | 直近のJobRunのitemsFetched | — | — |

### 2.3 ソース追加・編集フォーム

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| ソース名 | text | ○ | 表示名（例: "OpenAI Developers Changelog"） |
| URL | url | ○ | 取得対象URL |
| 種別 | select | ○ | official / rss / github / x |
| 取得方法 | select | ○ | rss / html_scrape / github_api / x_api / x_embed |
| 取得頻度 | select | ○ | hourly / daily / weekly |
| 信頼スコア | number(0.0〜1.0) | ○ | ソースの信頼度（デフォルト: 種別に応じた初期値） |
| 対象プロダクト | multi-select | ○ | Tag（product軸）との紐づけ |
| 法務メモ | textarea | — | 利用規約の確認状況、注意事項を記録 |
| robots.txt確認 | checkbox | ○ | 対象サイトのrobots.txtを確認済みであること |
| ステータス | select | ○ | active / paused / disabled |

### 2.4 操作

| 操作 | 説明 | 確認 |
|---|---|---|
| **追加** | 新規ソースを登録 | — |
| **編集** | 既存ソースの設定を変更 | — |
| **一時停止** | ステータスをpausedに変更（取得を停止） | 確認ダイアログ |
| **無効化** | ステータスをdisabledに変更（完全停止） | 確認ダイアログ |
| **削除** | ソースを削除（関連RawItem・Articleは保持） | 確認ダイアログ（二重確認） |
| **即時取得** | 次回スケジュールを待たずに即時取得を実行 | — |

### 2.5 法務メモの運用

法務メモには以下を記録する。

```
- 利用規約の確認日
- robots.txtの確認日と内容
- APIの利用制限（レート制限等）
- 注意すべき条項のメモ
- 法務判断の履歴
```

## 3. `/admin/jobs` — ジョブ管理

### 3.1 機能概要

収集パイプラインの実行履歴管理、障害対応、手動再実行を行う画面。

### 3.2 一覧画面

| カラム | 内容 | ソート | フィルター |
|---|---|---|---|
| ジョブ名 | FetchJob.name（daily_cron / manual_ingest等） | ○ | テキスト検索 |
| ソース | 対象Source.name | ○ | ドロップダウン |
| ステータス | pending / running / success / failed / retrying | ○ | ドロップダウン |
| 開始日時 | JobRun.startsAt | ○ | 日付範囲 |
| 終了日時 | JobRun.endsAt | ○ | — |
| 実行時間 | endsAt - startsAt（秒） | ○ | — |
| 取得件数 | JobRun.itemsFetched | ○ | — |
| エラー | JobRun.error（エラーメッセージの先頭100文字） | — | エラー有無 |

### 3.3 ジョブ詳細画面

| セクション | 内容 |
|---|---|
| 基本情報 | ジョブ名、ソース、ステータス、開始/終了日時、実行時間 |
| 取得結果 | 取得件数、新規RawItem数、重複スキップ数 |
| エラー詳細 | エラーメッセージ全文、スタックトレース |
| リトライ履歴 | リトライ回数、各回の実行日時とステータス |
| 取得アイテム一覧 | このジョブで取得されたRawItemのリスト |

### 3.4 操作

| 操作 | 説明 | 条件 |
|---|---|---|
| **手動再実行** | 失敗したジョブを再実行 | ステータスがfailedの場合のみ |
| **強制停止** | 実行中のジョブを中断 | ステータスがrunningの場合のみ |
| **バックオフ確認** | 現在のバックオフ状態を表示 | レート制限発生時 |
| **ログダウンロード** | ジョブの実行ログをダウンロード | — |

### 3.5 失敗ログとアラート

| 項目 | 仕様 |
|---|---|
| 失敗通知 | ジョブ失敗時に管理画面のヘッダーにバッジ表示 |
| 連続失敗 | 同一ソースで3回連続失敗した場合、ソースを自動pauseし警告表示 |
| バックオフ表示 | レート制限によるバックオフ中のソースをハイライト表示 |
| 実行統計 | 直近7日間の成功率・平均実行時間をダッシュボード表示 |

## 4. `/admin/articles` — 記事管理

### 4.1 機能概要

自動生成された記事の承認・非公開化・要約再生成・タグ編集・重複統合候補の確認を行う画面。

### 4.2 一覧画面

| カラム | 内容 | ソート | フィルター |
|---|---|---|---|
| タイトル | Article.title | ○ | テキスト検索 |
| ステータス | draft / published / unpublished / retracted / archived | ○ | ドロップダウン |
| プロダクト | Tag（product軸） | ○ | ドロップダウン |
| ラベル | Try / Monitor / Ignore | ○ | ドロップダウン |
| 総合スコア | totalScore | ○ | スライダー |
| 公開日時 | publishedAt | ○ | 日付範囲 |
| 重複候補 | 重複統合候補の有無 | — | あり/なし |

### 4.3 記事詳細・編集画面

#### 基本情報セクション

| フィールド | 操作 |
|---|---|
| タイトル | 編集可能 |
| スラッグ | 編集可能（変更時は旧URLからリダイレクト設定を促す） |
| ステータス | ドロップダウンで変更 |
| アクションラベル | Try / Monitor / Ignore を選択 |

#### 要約セクション

| フィールド | 操作 |
|---|---|
| 3行要約（summary3） | テキストエリアで編集 |
| 詳細要約（summaryLong） | テキストエリアで編集 |
| 何が変わったか（whatChanged） | テキストエリアで編集 |
| 誰に影響するか（whoImpacted） | テキストエリアで編集 |
| 推奨アクション（actions） | リスト形式で編集（追加/削除/並べ替え） |
| **要約再生成** | ボタン1クリックで元RawItemから要約を再生成 |

#### タグセクション

| 操作 | 内容 |
|---|---|
| タグ追加 | 4軸（product / theme / level / usecase）からタグを選択して追加 |
| タグ削除 | 既存タグを削除 |
| タグ候補提案 | 記事内容に基づく自動提案を表示 |

#### スコアセクション（管理者ビュー）

| 表示項目 | 操作 |
|---|---|
| 5軸スコア内訳 | 各次元のスコアをバーチャートで表示 |
| 総合スコア | 加重平均値を表示 |
| スコア手動調整 | 各次元のスコアを手動で上書き |

#### 出典・元データセクション

| 表示項目 | 操作 |
|---|---|
| 元RawItem一覧 | TopicClusterに属するRawItemのリスト |
| 出典URL | リンク付きで表示 |
| contentHash | ハッシュ値（元データの変更検知用） |

### 4.4 操作

| 操作 | 説明 | 確認 |
|---|---|---|
| **承認（Approve）** | draft → published に変更 | — |
| **非公開化（Unpublish）** | published → unpublished に変更 | 確認ダイアログ |
| **撤回（Retract）** | published → retracted に変更（誤情報・削除依頼対応） | 確認ダイアログ + 理由入力 |
| **アーカイブ** | published → archived に変更 | 確認ダイアログ |
| **要約再生成** | 元RawItemから要約を再生成（下書き上書き） | 確認ダイアログ |
| **一括承認** | チェックボックスで選択した複数記事を一括承認 | 確認ダイアログ |

### 4.5 重複統合候補（Dedup Candidates）

| 機能 | 説明 |
|---|---|
| 候補表示 | 正規化タイトルが類似する記事ペアを一覧表示 |
| 類似度 | Jaccard係数を表示（0.0〜1.0） |
| 統合操作 | 2記事を選択し、代表記事を指定して統合 |
| 統合結果 | 非代表記事は代表記事へのリダイレクトに変換 |
| 無視操作 | 候補を「統合不要」としてマーク |

## 5. `/admin/settings` — 設定

### 5.1 機能概要

サイト全体のSEO設定、法務・運用設定、監査ログの閲覧を行う画面。

### 5.2 SEO設定

| 設定項目 | 内容 |
|---|---|
| サイト名 | OGP・JSON-LDで使用するサイト名 |
| サイト説明 | metaタグ descriptionのデフォルト値 |
| デフォルトOGP画像 | サイト全体のデフォルトOGP画像URL |
| Google Search Console | 認証メタタグの設定 |
| sitemap設定 | 自動生成の有効/無効、対象ステータス |
| robots.txt設定 | Disallowパスの追加/削除 |

### 5.3 法務・運用（Legal / Ops）

#### 削除依頼管理

| カラム | 内容 |
|---|---|
| 依頼日時 | LegalEvent.createdAt |
| 依頼種別 | takedown / correction / source_block |
| 対象 | 記事URL / ソースURL |
| 依頼者 | 名前・連絡先 |
| ステータス | pending / in_review / resolved / rejected |
| 対応内容 | 非公開化 / 修正 / ソース停止 / 対応不要 |
| 対応日時 | LegalEvent.actedAt |
| 備考 | 法務判断の記録 |

#### 削除依頼フロー

```
1. 削除依頼を受領 → LegalEvent を pending で作成
2. 管理者が内容を確認 → in_review に変更
3. 対応実施:
   a. 記事非公開化 → Article.status を retracted に変更
   b. ソース停止 → Source.status を disabled に変更
   c. 修正 → 記事を編集
   d. 対応不要 → rejected に変更（理由を記録）
4. AuditLog に対応内容を記録
5. resolved に変更、actedAt を記録
```

#### 監査ログ（Audit Log）

| カラム | 内容 |
|---|---|
| 日時 | AuditLog.createdAt |
| 操作者 | AuditLog.actor |
| アクション | AuditLog.action（例: article_publish, source_disable, score_override） |
| 対象 | AuditLog.target（例: article:slug-name, source:openai-changelog） |
| 差分 | AuditLog.diff（JSON形式で変更前後を記録） |

| 操作 | 記録内容 |
|---|---|
| 記事承認/非公開化/撤回 | ステータス変更の前後 |
| ソース追加/停止/削除 | ソース情報の変更内容 |
| スコア手動調整 | 各次元の変更前後の値と理由 |
| 削除依頼対応 | 依頼内容と対応結果 |
| 設定変更 | 変更した設定項目と値 |

監査ログは削除不可。フィルター（日時範囲、操作者、アクション種別）と全文検索に対応する。

## 7. 実装上の注意事項

### 7.1 パフォーマンス

- 一覧画面はサーバーサイドページネーション（1ページ50件）
- ソート・フィルターはDBクエリで処理（クライアントサイドフィルターは避ける）
- 監査ログは大量になるため、日付範囲フィルターをデフォルト適用（直近30日）

### 7.2 セキュリティ

- すべての管理APIエンドポイントに認証チェックを実装
- CSRF対策を実装
- 入力値のバリデーション（Zodスキーマ）
- SQLインジェクション対策（Prisma ORMによるパラメータ化クエリ）

### 7.3 操作の取り消し

- 「非公開化」「撤回」は取り消し可能（ステータスをdraftに戻す）
- 「削除」は取り消し不可（確認ダイアログで二重確認）
- すべての操作はAuditLogに記録される
