# Project Brief — aiaiai

## プロダクト名（仮称）

**aiaiai** — 日々進化するAI情報を一手に集約する高品質日本語情報サイト

## プロダクトコンセプト

AIプロダクト（ChatGPT、Claude、Gemini、主要API/SDK）の更新情報を、**公式一次情報を最優先**に収集し、重複統合（Topic Cluster）と実務者向け再構成要約で「読む価値順」に提示する情報インフラ。

ニュース転載サイトではなく、**一次情報中心に更新を追跡し、実務判断できる形に再構成するプラットフォーム**。

## 差別化ポイント

1. **公式一次情報中心**の正確性とアップデート追跡性
2. **重複統合（Topic Cluster）**で「結局どれを読めばいいか」を1本に束ねる
3. **実務者向け再構成要約**（差分・影響・アクション）で一覧だけで判断可能
4. **スコアリング**による「読む価値順」の提示
5. X（Twitter）は規約遵守の範囲で速報補助、裏取り前は隔離ラベル

## 成功基準（MVP）

- [ ] 日次自動収集がCronで動作する

- [ ] 正規化・重複統合・要約・スコアリングが完走し公開ページに反映

## 技術スタック

| 領域 | 技術 | 理由 |
|---|---|---|
| フレームワーク | Next.js（App Router）+ TypeScript | Route HandlersでAPIとUI単一リポ運用 |
| DB | PostgreSQL + Prisma | ORM/マイグレーション/型安全 |
| UI | Tailwind CSS + shadcn/ui | 高速開発、BtoB適性 |
| 定期実行 | Vercel Cron Jobs | vercel.jsonでスケジュール定義 |
| 検索 | PostgreSQL FTS（MVP） | 将来Meilisearch等に差替可能 |
| デプロイ | Vercel | ゼロコンフィグ |

## 制約・遵守事項

1. **全文転載禁止**: 要約主体＋出典明記＋必要最小限の引用
2. **著作権法「引用」要件**: 公表物、公正な慣行、正当な範囲、出所明示
3. **X利用規約遵守**: スクレイピング禁止、API/埋め込みのみ
4. **robots.txt尊重**: 外部サイトのクロール制御を遵守
5. **削除依頼対応**: 記事単位で非公開/削除/ソース停止を即時実行可能
6. **誤情報隔離**: SNS速報は隔離ラベルで管理
7. **監査ログ**: 法務リクエスト・削除・ソース遮断はすべてログ記録
