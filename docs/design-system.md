# デザインシステム — aiaiai

## 概要

aiaiaiのデザインシステムは「信頼性」「可読性」「効率性」を軸とする。BtoB向けの情報サイトとして、視覚的な派手さよりも情報の整理と読みやすさを優先する。Tailwind CSS + shadcn/ui をベースに、日本語テキストの可読性に最適化したコンポーネント群を構築する。

---

## 1. タイポグラフィ

### 1.1 基本方針

- 日本語の可読性を最優先にする
- 本文はゴシック体（sans-serif）を基本とする
- 行間・文字間を広めに取り、長文でも疲れない設計にする

### 1.2 フォントスタック

```css
/* 本文 */
font-family: "Noto Sans JP", "Hiragino Kaku Gothic ProN", "Hiragino Sans",
             "BIZ UDPGothic", Meiryo, sans-serif;

/* コード・技術情報 */
font-family: "JetBrains Mono", "Fira Code", "Source Code Pro",
             "Noto Sans Mono CJK JP", monospace;
```

- `next/font` でNoto Sans JPをセルフホスティングし、CLS（Cumulative Layout Shift）を防止する
- ウェイトは Regular(400) と Bold(700) の2種を読み込む

### 1.3 フォントサイズ・行間

| 要素 | フォントサイズ | 行間（line-height） | 用途 |
|---|---|---|---|
| 見出し1（h1） | 28px / 1.75rem | 1.4 | ページタイトル |
| 見出し2（h2） | 24px / 1.5rem | 1.4 | セクション見出し |
| 見出し3（h3） | 20px / 1.25rem | 1.5 | サブセクション見出し |
| 見出し4（h4） | 16px / 1rem | 1.5 | 小見出し |
| 本文 | 16px / 1rem | 1.8 | 記事本文・説明 |
| 小テキスト | 14px / 0.875rem | 1.6 | 補足・メタ情報 |
| 最小テキスト | 12px / 0.75rem | 1.5 | バッジ・タイムスタンプ |

### 1.4 行間・余白の設計思想

| 項目 | 値 | 理由 |
|---|---|---|
| 本文行間 | 1.8 | 日本語は文字が詰まりやすいため、英語（1.5）より広めに設定 |
| 段落間余白 | 1.5em | 段落の区切りを明確にする |
| 見出し前余白 | 2em | セクションの区切りを視覚的に強調 |
| 見出し後余白 | 0.5em | 見出しと本文の関連性を維持 |
| 文字間 | 0.02em | わずかに広げて密集感を軽減 |

### 1.5 見出し階層

```
h1: ページタイトル（1ページに1つのみ）
  h2: 主要セクション
    h3: サブセクション
      h4: 詳細項目
```

- h1はページ内に1つのみ使用する
- 見出しレベルの飛ばし（h1→h3）は禁止
- 見出しは簡潔に（40文字以内を推奨）

## 2. カラーパレット

### 2.1 基本方針

- BtoB向けの信頼感・清潔感のあるカラーパレット
- コントラスト比はWCAG AA基準（4.5:1以上）を遵守
- ダークモード対応を前提に、CSS変数で管理する

## 4. レスポンシブデザイン

### 4.1 基本方針

- モバイルファーストで設計し、ブレークポイントで拡張する
- 公開ページはモバイルでの可読性を最優先する
- 管理画面はデスクトップ操作を前提とする（最小幅 1024px）

### 4.2 ブレークポイント

| 名称 | 幅 | Tailwindクラス | 対象デバイス |
|---|---|---|---|
| Mobile | 0〜639px | デフォルト | スマートフォン |
| Tablet | 640〜1023px | `sm:` | タブレット |
| Desktop | 1024〜1279px | `lg:` | ノートPC |
| Wide | 1280px〜 | `xl:` | デスクトップ |

### 4.3 レイアウトパターン

#### 公開ページ

| ブレークポイント | レイアウト |
|---|---|
| Mobile | 1カラム、カードは縦積み |
| Tablet | 1カラム、カードは2列グリッド |
| Desktop | サイドバー + メインコンテンツ、カードは2列グリッド |
| Wide | サイドバー + メインコンテンツ、カードは3列グリッド |

#### 管理画面

| ブレークポイント | レイアウト |
|---|---|
| Desktop以上 | 固定サイドバー（240px） + メインコンテンツ |
| Tablet以下 | ハンバーガーメニュー + フルワイドコンテンツ |

### 4.4 タッチ対応

- タップ可能な要素は最小44x44pxを確保する
- スワイプ操作は使用しない（誤操作防止）
- ホバー依存のUIはモバイルでタップで代替する

## 5. バッジシステム

### 5.1 基本方針

記事カードや一覧で、情報の性質を即座に視認できるバッジ群を提供する。バッジは小さく、色とテキストで識別する。

### 5.2 アクションラベルバッジ

| バッジ | 色 | テキスト | 用途 |
|---|---|---|---|
| Try | Green（`bg-green-100 text-green-800`） | 試す | すぐに試す価値がある |
| Monitor | Amber（`bg-amber-100 text-amber-800`） | 注視 | 動向を注視すべき |
| Ignore | Gray（`bg-gray-100 text-gray-600`） | 様子見 | 大多数に影響なし |

### 5.3 信頼度バッジ

| レベル | 条件 | 色 | テキスト |
|---|---|---|---|
| 高信頼 | scoreTrust >= 0.8 | Blue（`bg-blue-100 text-blue-800`） | 公式 |
| 中信頼 | 0.5 <= scoreTrust < 0.8 | Slate（`bg-slate-100 text-slate-700`） | 準公式 |
| 低信頼 | scoreTrust < 0.5 | Yellow（`bg-yellow-100 text-yellow-800`） | 未検証 |

### 5.4 重要度バッジ

| レベル | 条件 | 色 | テキスト |
|---|---|---|---|
| 重大 | scoreImportance >= 0.8 | Red（`bg-red-100 text-red-800`） | 重大 |
| 重要 | 0.5 <= scoreImportance < 0.8 | Orange（`bg-orange-100 text-orange-800`） | 重要 |
| 通常 | scoreImportance < 0.5 | 表示なし | — |

### 5.5 緊急度バッジ

| レベル | 条件 | 色 | テキスト |
|---|---|---|---|
| 緊急 | scoreUrgency >= 0.7 | Red（`bg-red-100 text-red-800`） | 緊急 |
| 要注意 | 0.4 <= scoreUrgency < 0.7 | Amber（`bg-amber-100 text-amber-800`） | 要注意 |
| 通常 | scoreUrgency < 0.4 | 表示なし | — |

### 5.6 検証状態バッジ

| 状態 | 色 | テキスト |
|---|---|---|
| verified | 表示なし（通常記事） | — |
| unverified | Yellow（`bg-yellow-100 text-yellow-800`） | 速報（未検証） |
| retracted | Red（`bg-red-100 text-red-800`） | 撤回済み |

### 5.7 プロダクトバッジ

| プロダクト | 色 | アイコン |
|---|---|---|
| ChatGPT | OpenAI Green背景 | OpenAIロゴ |
| Claude | Claude Tan背景 | Anthropicロゴ |
| Gemini | Google Blue背景 | Googleロゴ |


### 6.2 カード要素

| 要素 | 内容 | 位置 |
|---|---|---|
| プロダクトバッジ | プロダクト名 + カラー | 左上 |

| タイトル | 記事タイトル（最大2行） | 中央上 |
| 3行要約 | summary3（最大3行） | 中央 |
| スコアバー | totalScoreの視覚表示 | 下部 |

### 6.3 カードのバリエーション

| バリエーション | 用途 | 特徴 |
|---|---|---|
| 標準カード | 一覧ページ | 上記の完全レイアウト |
| コンパクトカード | サイドバー・関連記事 | タイトル + バッジのみ |
| ハイライトカード | 週次ダイジェストのトップ3 | 大きめ、背景色付き |
| 速報カード | 未検証記事 | 黄色ボーダー、「速報（未検証）」バッジ強調 |

```css
  grid-template-columns: repeat(2, 1fr);

  grid-template-columns: repeat(3, 1fr);
```

## 7. アイコンとイラスト

### 7.1 アイコン

- Lucide Icons（shadcn/uiのデフォルト）を使用する
- アイコンサイズは16px / 20px / 24pxの3段階
- アイコンには必ずaria-labelまたはテキストラベルを併用する（アクセシビリティ）

### 7.2 ロゴ

- サイトロゴはSVG形式で作成する
- ヘッダー表示サイズ: 高さ32px
- OGP画像表示サイズ: 高さ64px
- ファビコン: 32x32px、16x16px

## 8. アクセシビリティ

### 8.1 遵守基準

- WCAG 2.1 AA 準拠を目標とする

### 8.2 主な対応事項

| 項目 | 対応 |
|---|---|
| コントラスト比 | テキスト: 4.5:1以上、大テキスト: 3:1以上 |
| キーボード操作 | すべてのインタラクティブ要素にフォーカス可能 |
| スクリーンリーダー | 画像にalt属性、アイコンにaria-label |
| フォーカス表示 | `focus-visible` でフォーカスリングを表示 |
| 色のみに依存しない | バッジは色 + テキストで情報を伝える |
| `lang` 属性 | `<html lang="ja">` を設定 |
